# Libraries

Cashu libraries allow developers to build wallets, mints, and other services that use Cashu.

## Python

- [Nutshell](https://github.com/cashubtc/nutshell): Python library for using Cashu wallets and mints inside Python applications.
- [cdk-python](https://github.com/cashubtc/cdk-python): Python bindings for the Cashu Development Kit (CDK).

## TypeScript & JavaScript

- [cashu-ts](https://github.com/cashubtc/cashu-ts): TypeScript library for building Cashu wallets.
- [Coco](https://github.com/cashubtc/coco): Modular, TypeScript-first toolkit for building Cashu wallets and applications.
- [cashu-crypto-ts](https://github.com/cashubtc/cashu-crypto-ts): TypeScript library implementing the basic cryptographic blinded signature scheme.

## Rust

- [cdk](https://github.com/cashubtc/cdk): Cashu Development Kit (CDK) mint and wallet library.

## Go

- [cdk-go](https://github.com/cashubtc/cdk-go): Go bindings for the Cashu Development Kit (CDK).

## Kotlin

- [cdk-kotlin](https://github.com/cashubtc/cdk-kotlin): Kotlin bindings for the Cashu Development Kit (CDK).

## Swift

- [cdk-swift](https://github.com/cashubtc/cdk-swift): Swift bindings for the Cashu Development Kit (CDK).
- [CashuSwift](https://github.com/zeugmaster/CashuSwift): Native Swift library for Cashu.

## Java

- [Cashu-JDK](https://github.com/d4rp4t/Cashu-JDK): Minimal, stateless reimplementation of the Cashu protocol in Java.
