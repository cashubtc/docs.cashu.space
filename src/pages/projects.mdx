# Highlighted Cashu projects

## Athenut

[Athenut](https://github.com/thesimplekid/athenut-frontend) is a privacy-preserving web search engine powered by Kagi and Cashu.

## BTCNutServer

[BTCNutServer](https://github.com/d4rp4t/BTCNutServer) enables BTCPay Server to accept Bitcoin payments via Cashu tokens.

## hashpool

[hashpool](https://github.com/vnprc/hashpool) is an accountless mining pool that uses ecash to represent mining shares.

## npub.cash

[npubcash-server](https://github.com/cashubtc/npubcash-server) uses Cashu mints to receive funds via Lightning addresses.

## Numo

[Numo](https://numopay.org/) is a Bitcoin point-of-sale (POS) app that lets merchants accept Bitcoin payments with a simple tap.

## Orchard

[Orchard](https://github.com/cashubtc/orchard) is a web application for Cashu mint management.

## Redeem

[Redeem](https://redeem.cashu.me/) is a web tool that lets you redeem Cashu tokens directly to a Lightning wallet without needing a Cashu wallet ([GitHub](https://github.com/cashubtc/cashu-redeem)).

## routstr

[routstr](https://github.com/routstr) is a marketplace to buy and sell LLM APIs using Cashu ecash tokens.

## TollGate

[TollGate](https://github.com/OpenTollGate/tollgate-app) turns any Wi-Fi router into a decentralized ISP using Bitcoin and ecash.
