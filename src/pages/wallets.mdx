# Cashu wallets

## Agicash

[Agicash](https://github.com/MakePrisms/agicash) is a wallet designed for fast, easy onboarding and use.

## Cashu.me

[Cashu.me](https://cashu.me) is a native wallet for iPhone and Android.

## Cashu.me (PWA)

[Cashu.me (PWA)](https://github.com/cashubtc/cashu.me) is a progressive web app (PWA) wallet for Cashu.

## Minibits

[Minibits](https://github.com/minibits-cash/minibits_wallet) is a mobile Cashu wallet with a focus on performance and usability.

## Macadamia

[Macadamia](https://github.com/zeugmaster/macadamia) is a Cashu wallet for iOS written in Swift.

## Sovran

[Sovran](https://github.com/SovranBitcoin/Sovran) is a Cashu wallet for iOS.

## Nutstash

[Nutstash](https://nutstash.app/) is a Cashu web wallet with many features such as multi-mint support and sending and receiving tokens via Nostr. Nutstash is written in TypeScript and uses the [cashu-ts](https://github.com/cashubtc/cashu-ts) library.

## cdk-wallet

[cdk-wallet](https://github.com/cashubtc/cdk) is a CLI wallet written in Rust.

## Nutshell

[Nutshell](https://github.com/cashubtc/nutshell) is a CLI wallet available through PyPI. It is the [first](https://twitter.com/callebtc/status/1569986110272540674) Cashu wallet and mint. Both the mint and the wallet can be used as standalone software or included into other applications as a library. It has full Bitcoin Lightning integration, PostgreSQL and SQLite database support, built-in Tor, supports multiple mints, can send and receive tokens on Nostr, and supports tokens with complex spending conditions.
